# bind_forms

Model-driven forms for Flutter that bind to real widgets instead of wrapping them.

| Package | Description |
| --- | --- |
| [`bind_forms_core`](packages/bind_forms_core) | Pure Dart form model: controls, groups, arrays, validators. |
| [`bind_forms`](packages/bind_forms) | Flutter adapters (`TextEditingController`, `ValueListenable`) over the core. |

Planned: `bind_forms_signals`, optional adapters for the `signals` package.
